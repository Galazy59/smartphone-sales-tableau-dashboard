#Global Smartphone Sales & Camera Benchmark Dashboard (Tableau)

An interactive Tableau data visualization project analyzing flagship and mainstream smartphone performance, market adoption volume, revenue generation, and camera specifications (DxOMark benchmarks).

##Dataset Overview
This dataset contains key commercial and technical metrics for leading smartphone models released across major manufacturers (Apple, Samsung, Google, Xiaomi, Oppo, OnePlus, and Vivo).

### Key Features Included:
* **Market Data:** Model name, Brand, Market Segment, Retail Price (USD), Volume Sold (Units), and Calculated Revenue.
* **Camera Specifications:** Main sensor resolution/aperture, Telephoto zoom specs, Ultrawide specs, and Selfie camera resolution.
* **Industry Benchmarks:** DxOMark camera quality scores for value-to-performance analysis.

## 🗂️ File Structure
* `smartphone_sales_dataset.csv` — The core dataset ready for Tableau connection.
* `smartphone_sales_dataset.xlsx` — Formatted Excel version with headers and number formatting.
